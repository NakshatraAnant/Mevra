# Master high-resolution files

**Empty by design until generation runs.** No photographic masters exist yet (no image model in the production environment).

When each image is generated, save the untouched full-resolution output here, mirroring the page folder path, as PNG (or TIFF), e.g. `12_MASTER_HIGH_RESOLUTION/01_HOMEPAGE/Hero/homepage-hero-desktop.png`. Target master size per asset is in the manifest (`Master size` column): 2x the web size, or 1.6x for assets already wider than 1600 px.

Vector assets (SVG) are their own masters and are not duplicated here.
