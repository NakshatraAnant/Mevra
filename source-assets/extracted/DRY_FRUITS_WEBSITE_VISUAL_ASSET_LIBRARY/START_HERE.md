# START HERE — Dry Fruits Website Visual Asset Library

## Status
This is an initial production handoff, **not a complete website asset library**. One AI-generated desktop hero candidate has been created and exported. The rest of the required library is inventoried as planned work and is not represented by placeholder images.

## What is included
- One desktop homepage hero candidate in WebP.
- Its 1536 × 1024 PNG master.
- A complete planned asset inventory covering homepage, categories, all eight launch SKUs, gifting, B2B, standards and bundles.
- Website mapping, visual direction, research notes, generation prompt and missing-information / QA reports.

## How to locate assets
- `01_HOMEPAGE/Hero/` — current desktop hero WebP.
- `11_DESKTOP_ASSETS/` — desktop delivery copy.
- `12_MASTER_HIGH_RESOLUTION/` — original PNG master.
- `13_IMAGE_GENERATION_PROMPTS/` — prompt records.
- `14_VISUAL_REFERENCE_RESEARCH/` — research notes.
- `15_DOCUMENTATION/` — implementation and QA documentation.

## Developer instructions
1. Use the hero WebP only as a visual candidate, not as approved production photography.
2. Do not use the concept-board images from the generation session; they contain synthetic layouts/text and are not individual production assets.
3. Do not infer packaging labels, product facts, legal declarations, QR destinations, lot certificates or claims from generated imagery.
4. Build all typography, prices, labels, CTAs and product facts in code.
5. Generate dedicated mobile hero and product/category images before calling the visual implementation complete.
6. Check the PowerPoint slides 30–35 for the website mockups and page structure; slides 26–27 for brand identity and naming caveats.
